# Perspective Studio

A React + Vite app for exploring how historical thinkers and writers would frame a
modern topic. Each author card carries an era, place, recurring themes, major works,
and a reconstruction prompt — responses are labelled as AI reconstructions grounded
in the author's writings, never as the historical person speaking.

**Status: work in progress.**

## Stack

React 19, Vite, Tailwind CSS v4, Framer Motion, lucide-react.

## Running it

```bash
npm install
npm run dev      # dev server
npm run build    # production build
npm run lint
```

## Layout

- `src/App.jsx` — the whole app, including the starter author set
- `src/assets/` — hero image and icons
- `public/` — favicon and icon sprite
